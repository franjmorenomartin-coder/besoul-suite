# Prompt inicial para Codex

Copia y pega este prompt en Codex después de subir estos archivos al repositorio:

```text
Trabaja como CTO senior, product manager y arquitecto principal de BESOUL Suite.

Este repositorio contiene una app real en producción. Antes de editar nada:
1. Lee todo el repositorio.
2. Lee AGENTS.md, README.md, BUSINESS_CONTEXT.md, FIREBASE_SCHEMA.md, SECURITY_RULES.md, ROADMAP.md y TEST_PLAN.md.
3. Identifica arquitectura actual, flujos de negocio y modelo de datos.
4. No edites archivos todavía.

Quiero primero un informe técnico completo con:
- arquitectura actual,
- riesgos técnicos,
- riesgos de seguridad,
- duplicidades,
- puntos frágiles,
- prioridades,
- plan por fases para profesionalizar la app sin romper producción.

Regla fundamental: no rompas nada que ya funciona. Cambios pequeños, seguros y verificables.
```
