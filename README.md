# BESOUL Suite

BESOUL Suite is a production web/PWA system for BESOUL Fitness.

It manages:

- Trainer agenda.
- Clients and groups.
- CRM leads and trial sessions.
- Finance calculations and trainer settlements.
- Company expenses.
- Executive dashboard.
- Customer booking requests.
- PWA installation.

## Current deployment

The app currently runs on GitHub Pages.

Main pages:

- `index.html`
- `agenda.html`
- `crm.html`
- `finanzas.html`
- `dashboard.html`
- `reservas.html`

## Technology

- Static HTML/CSS/JavaScript.
- Firebase Authentication.
- Firestore.
- GitHub Pages.
- PWA manifest and service worker.

Read `AGENTS.md`, `BUSINESS_CONTEXT.md`, `FIREBASE_SCHEMA.md`, `SECURITY_RULES.md`, `ROADMAP.md` and `TEST_PLAN.md` before modifying the app.
